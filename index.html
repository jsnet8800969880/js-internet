🔑 Password Management

Staff ya Customer ka login password sirf Admin yahan se change kar sakta hai.

⚠️ Spark plan limitation: website ke andar Admin kisi doosre Staff/Customer ka Firebase Authentication password directly set nahi kar sakta. Firebase Admin SDK/Cloud Functions ke bina target user ka password browser se change karna supported nahi hai.

Admin ka kaam: neeche account ka Login Email milega. Open Firebase Authentication se Users page kholo.
1. Target user ko search karo.
2. User par click/⋮ menu open karo.
3. Firebase Console mein available password-reset option use karo.

Important for this project: hamare current Staff/Customer emails @jsinternet.local hain, isliye reset email kisi real inbox mein nahi ja sakta. Email-based reset tabhi useful hoga jab account par real reachable email ho.
